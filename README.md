# Memory Allocation Algorithms

This repository contains an implementation of memory allocation algorithms
using linked lists.

The following algorithms are implemented:
- Best Fit
- Worst Fit
- Next Fit

The memory size is simulated as 100 units.

---

## Files

- best_fit.py : Best Fit allocation algorithm
- worst_fit.py : Worst Fit allocation algorithm
- next_fit.py : Next Fit allocation algorithm
- experiment.py : Scripts used for running experiments and tests

---

## How to Run

1. Make sure Python 3 is installed.
2. Clone the repository.
3. Run the experiment file.

Example:
python experiment.py

---

## Experiments

The code includes:
- Allocation trace experiments
- Fragmentation tests
- Speed tests

The results are printed to the console.
